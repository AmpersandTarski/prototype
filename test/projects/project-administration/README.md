# project-administration — regression vehicle

**Guards:** that a classic Ampersand demo model compiles and installs on the bundled
compiler: an `INCLUDE`d xlsx population, an `INCLUDE`d `.ifc` file, `DEFAULT TGT VALUE`,
role-restricted interfaces (`FOR Planner`, `FOR Projectleader`), an ExecEngine rule
(`InsPair`), `BOX<TABLE sortable sortBy order>` and dotted (namespaced) concept and
relation names next to plain ones.

**Origin:** the Ampersand "Project Administration" demo; the model was rewritten to the
v5 `RELATION` syntax on 2026-08-30 (the v3 `rel :: A * B` form no longer parses).

**Run:** `test/run-regression.sh project-administration`

**Green means:** the model compiles and the installer succeeds. There is no spec yet:
the runner reports "no spec", which is the intended verdict until a browser spec exists.
